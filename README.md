## این پروژه چیست؟

یک پنل ادمین ساده و زیبا که با آن می‌توانید چند پروکسی MTProto (از نوع Fake-TLS) بسازید، لینکشان را کپی کنید، فعال یا غیرفعال کنید و حذف کنید. روی Railway اجرا می‌شود.

> هر پروکسی یک secret جدا دارد و همه روی یک پورت مشترک کار می‌کنند.

## پیش‌نیازها

- یک حساب [GitHub](https://github.com)
- یک حساب [Railway](https://railway.com)

## نصب روی Railway

### ۱. آپلود پروژه

پوشهٔ پروژه را در یک ریپوی جدید در GitHub بگذارید (می‌توانید Private باشد).

### ۲. ساخت سرویس

در Railway گزینهٔ **New Project ← Deploy from GitHub repo** را بزنید و ریپو را انتخاب کنید. Railway خودش `Dockerfile` را تشخیص می‌دهد و بیلد می‌کند.

### ۳. تنظیم متغیرها

در تب **Variables** این‌ها را اضافه کنید:

| متغیر | مقدار | توضیح |
|---|---|---|
| `ADMIN_USER` | نام دلخواه | نام کاربری ورود به پنل |
| `ADMIN_PASS` | رمز قوی | رمز ورود به پنل |
| `PORT` | `3000` | پورت پنل وب |

> ⚠️ حتماً `ADMIN_USER` و `ADMIN_PASS` را عوض کنید. مقدار پیش‌فرض هر دو `admin` است.

### ۴. آدرس پنل

در **Settings ← Networking ← Public Networking** روی **Generate Domain** بزنید و پورت `3000` را انتخاب کنید. آدرسی که می‌گیرید آدرس پنل شماست.

### ۵. باز کردن پورت پروکسی (TCP Proxy)

در همان بخش Networking گزینهٔ **TCP Proxy** را اضافه کنید و پورت مقصد را `8443` بگذارید. Railway یک آدرس و پورت به شما می‌دهد، مثلاً:

```
xxxx.proxy.rlwy.net:12345
```

این دو مقدار را نگه دارید، در مرحلهٔ بعد لازم می‌شوند.

### ۶. اضافه کردن Volume

بدون Volume با هر دیپلوی جدید همهٔ پروکسی‌ها پاک می‌شوند.

در Railway یک **Volume** بسازید و مسیر Mount را روی `/data` بگذارید.

### ۷. تنظیم پنل

1. آدرس پنل را باز کنید و با `ADMIN_USER` و `ADMIN_PASS` وارد شوید.
2. در بخش **تنظیمات اتصال**، آدرس (host) و پورتی را که در مرحلهٔ ۵ گرفتید وارد کنید و **ذخیره** بزنید.
3. در بخش **ساخت پروکسی جدید** یک نام بدهید و **ساخت** را بزنید.
4. روی **کپی لینک** یا **افزودن به تلگرام** بزنید و لینک را برای کاربران بفرستید.

## اجرای محلی (اختیاری)

برای تست روی کامپیوتر خودتان (Docker لازم است):

```bash
docker build -t star-proxy .
docker run -p 3000:3000 -p 8443:8443 -e PORT=3000 -e ADMIN_USER=admin -e ADMIN_PASS=1234 star-proxy
```

سپس `http://localhost:3000` را باز کنید. برای تست واقعی، در تنظیمات اتصال host را آی‌پی سرور و port را `8443` بگذارید.

## عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| پنل باز نمی‌شود | مطمئن شوید `PORT=3000` را گذاشته‌اید و دامنه روی همان پورت ساخته شده. |
| وضعیت سرویس «متوقف» است | باید حداقل یک پروکسی فعال بسازید. |
| تلگرام وصل نمی‌شود | آدرس و پورت TCP Proxy را در تنظیمات اتصال چک کنید و مطمئن شوید پورت مقصد `8443` است. |
| پروکسی‌ها بعد از دیپلوی پاک شدند | Volume را روی `/data` اضافه کنید. |
| رمز ورود را فراموش کردم | مقدار `ADMIN_PASS` را در Variables عوض کنید تا سرویس دوباره دیپلوی شود. |

## نکته دربارهٔ ۳۰ روز

پنل بعد از نصب یک پیام خوش‌آمد نشان می‌دهد که طبق آن پنل تا ۳۰ روز فعال است و به دلایل هاستینگ Railway بعد از آن غیرفعال می‌شود. این فقط یک پیام است و خود پنل محدودیتی اعمال نمی‌کند.
